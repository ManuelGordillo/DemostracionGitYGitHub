### Acceder a su rama creada con su nombre
    git checkout nombreRama

### Subir cambios a su rama
    git add .
    git commit -m "Escribir mensaje coherente con lo hecho o modificado"
    git push

### Subir cambios a la rama principal que manejaremos main o master
    primero cambiar a rama main o master segun cual manejemos en
    luego
    git merge laRamadeustedes main o master 

### descargar cambios hechos por otros a nuestra rama
    git fetch
